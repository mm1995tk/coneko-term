# AGENTS.md

Instructions for coding agents working in this repository. Humans: see the "Development" section of the [README](README.md).

## Project

- coneko-term is a library of terminal building blocks. The VT parser and the screen (cells, cursor, scrollback) are written in Rust and compiled to WebAssembly. Drawing is TypeScript on Canvas 2D.
- It is a separate project from kitty. Call it **coneko-term** in user-facing text.
- Layout:
  - `crates/coneko-term`: the core. It must not depend on the browser (no `wasm-bindgen`, no `web-sys`), so a native GPU renderer can use it too.
  - `crates/coneko-term-wasm`: the `wasm-bindgen` bindings. Keep it thin.
  - `src/`, `test/`, `package.json`: the npm package `coneko-term` (WASM and TypeScript types). `src/wasm/` is generated by `scripts/build-wasm.sh` and is not committed.
- The npm package ships the built `.wasm` in `dist/wasm/`. Do not rely on install scripts (`postinstall` and so on): shijimi-editor builds it with `npm --ignore-scripts`.

## Before you finish a change

Run these from the Nix devShell (`nix develop`, or `direnv allow`). Do not install Rust or Node by other means.

```sh
cargo test           # must pass
npm ci --ignore-scripts && npm run build && npm test   # builds the WASM and the package, runs the TypeScript tests
nix fmt              # must leave no changes (nixfmt / rustfmt / taplo / prettier)
nix flake check      # what CI runs: formatting, cargo test, and the npm package build with its tests
```

Run every command from the root of the repository.

## Rules that CI or tests enforce

- **Dependencies**: after changing `Cargo.toml`, commit the updated `Cargo.lock`. The `wasm-bindgen` crate version must equal the `wasm-bindgen-cli` version in nixpkgs (the build fails with a schema version error otherwise).
  After changing `package-lock.json`, update `npmDepsHash` in `flake-packages.nix` (set it to `lib.fakeHash`, run `nix build .#npm`, and copy the hash it prints).
  After adding or changing a `uses:` in `.github/workflows/`, update `.github/workflows/actions.lock` (`gh actions-lock`).
